# City Star Hotel - Web Platform (Frontend)

## Technology Stack
- Next.js 15+ (App Router)
- TypeScript
- Tailwind CSS
- Lucide React Icons
- TanStack Query (React Query)
- Supabase Auth Client

## Architecture
- Fully decoupled client consuming headless REST endpoints from `@citystar/api` (`https://citystaraccomodation.onrender.com/api/v1`).
- Shared domain contracts and TypeScript models.
